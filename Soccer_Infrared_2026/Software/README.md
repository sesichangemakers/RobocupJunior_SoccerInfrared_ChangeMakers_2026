<h1>Software</h1>

<p>Directory dedicated to the software developed for the Soccer Infrared robots by the SESI ChangeMakers team.</p>

<h2>Contents</h2>
<ul>
	<li><a href="CRONOS/">CRONOS:</a> software for the team's defender robot.</li>
	<li><a href="NEXUS/">NEXUS:</a> software for the team's attacker robot.</li>
	<li><a href="testes/">Tests:</a> code used to test robot functionalities.</li>
</ul>

<h2>Purpose</h2>
<p>To organize the code for each robot and the functional tests used during development, making it easier to locate and maintain the team's software.</p>
